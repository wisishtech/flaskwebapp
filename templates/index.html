What This App Demonstrates

Flask Routing

Routes defined using Flask decorators handle GET and POST HTTP requests and render Jinja2 HTML templates dynamically (Ronacher, 2023).

MySQL Integration

User data is stored securely in a MySQL database table (tbl_user) using the mysql-connector-python library (Oracle Corporation, 2023).

Password Hashing

Passwords are hashed using Werkzeug's pbkdf2:sha256 algorithm before storage, ensuring plain text credentials are never saved (Viega & Messier, 2003).
